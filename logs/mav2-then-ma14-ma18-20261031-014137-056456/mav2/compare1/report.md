# MAV2：基础量化、选择性变换与强制 D8 的同场完整训练

本次 36 个正式窗口、1800 个正式 optimizer step；每窗口 10 步预热＋50 步计时。
三组均覆盖 Attention＋MLP、固定全远端量化、136 B 包、同一 GEMM 和 NCCL。basic 全 H8；mav2 逐组选择 D8/H8；d8 强制全部直接量化且不运行选择器。
每个候选独立对照 basic：逐点 loss 门槛为 0.05+5%×对照绝对值，grad_norm 为 0.1+10%×对照绝对值。
短程数值门禁通过：False。逐 rank/逐窗口误差、均值/末步比与归一化 RMSE 保存在 JSON quality 字段。
三组没有预设耗时排序；负结果全部保留。

本批次显式允许质量超限后继续性能测量；数值门槛未放宽，预检与正式窗口的质量失败均计入最终判定。

**质量门禁未通过：流程完成不代表数值合格；质量失败的比较不能认定为合格加速。**
